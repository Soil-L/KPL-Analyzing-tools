# 故障排查

## 启动窗口一闪而过

请从项目根目录运行：

```text
start-local.bat
```

新版脚本会在失败时保留窗口。如果仍然闪退，可在命令提示符中进入项目目录并运行：

```bat
start-local.bat
```

将完整错误信息附在 Issue 中。

## 找不到 `py` 或 `python`

安装 Python 3.10+，并在安装时启用“Add Python to PATH”。然后重新打开命令窗口验证：

```bash
python --version
```

## 浏览器没有自动打开

保持启动窗口开启，手动访问：

<http://127.0.0.1:8765/>

如果地址无法打开，检查窗口中是否出现端口占用或 Python 异常。

## 8765 端口被占用

通常表示程序已经运行。先直接访问本地地址。

如果另一个程序占用了端口，关闭对应程序后重新启动。目前端口在 `local_app.py` 中固定为 `8765`。

## 视频无法读取

检查：

- 路径必须是本机绝对路径；
- 文件扩展名是否受支持；
- 文件是否正在同步或仅存在于云端占位；
- OpenCV 是否能解码该编码；
- 文件名和路径是否有访问权限。

可先把视频复制到一个短路径测试。

## 校准画面为空

- 校准秒数不能超过视频时长。
- 填写的是视频秒数，不是游戏内秒数。
- 每场视频都必须单独填写秒数并读取。

## 自动识别不足 10 个头像

尝试：

1. 换到附近几秒；
2. 选择十个头像分散、清晰的画面；
3. 删除误识别标记；
4. 切换蓝方或红方添加模式；
5. 在缺失头像中心手动补点。

开始分析前必须保证蓝方 5 个、红方 5 个。

## 轨迹与视频位置不一致

先排查：

- 校准圆点是否位于头像中心；
- 回放倍速是否与视频一致；
- 开局偏移是否正确；
- 小地图裁剪是否覆盖正确区域；
- 是否处于头像死亡、重叠或特效遮挡时刻。

虚线标记代表较低置信度。置信度低于 50% 的位置默认不显示。

## 分析速度很慢

当前算法使用 CPU，并在每个采样帧执行十次全图头像匹配。

可将采样间隔从 2 秒改为 4 秒，分析帧数通常减少一半。批量任务为串行执行，总耗时会随视频数量增长。

## 概率表为空

逐场检查：

- 红蓝双方队名均已填写；
- 每方五个英雄都选择了分路；
- 每方五个分路没有重复；
- 查询时间没有超过所有比赛时长；
- 该时间点存在置信度不低于 50% 的样本。

## CSV 中文乱码

程序导出的 CSV 已包含 UTF-8 BOM。若其他工具仍显示乱码，请在导入时显式选择 UTF-8 编码，不要直接按系统默认 ANSI 打开。

## 提交 Issue 前

请附上：

- 操作系统和 Python 版本；
- 视频分辨率、时长、倍速；
- 校准秒数和采样间隔；
- 错误信息或进度位置；
- 不含版权或隐私内容的最小截图；
- 是否能稳定复现。
