# 区域分类规则

概率统计把每个有效轨迹点分类为七个互斥区域：

```text
己方红区
己方蓝区
对方红区
对方蓝区
对抗路
中路
发育路
```

## 1. 坐标方向

地图坐标范围为 0–100：

```text
(0,0) ─────────── (100,0)
  │                   │
  │       (50,50)     │
  │                   │
(0,100) ──────── (100,100)
```

蓝色方基地位于左下附近，红色方基地位于右上附近。

## 2. 分类优先级

分路走廊优先于野区方向。一个点只会被分入一个区域。

### 中路

中路近似为反对角线：

```text
|x + y - 100| <= 8
```

并限制 `x` 在 12–88 之间，避免把基地附近全部判为中路。

### 对抗路

对抗路近似为地图上方和左侧的 L 形道路：

```text
|x - 14| <= 7，且 y 在 12–88
或
|y - 14| <= 7，且 x 在 12–88
```

### 发育路

发育路近似为地图下方和右侧的 L 形道路：

```text
|x - 86| <= 7，且 y 在 12–88
或
|y - 86| <= 7，且 x 在 12–88
```

## 3. 野区方向

不属于分路走廊的点，以地图中心 `(50, 50)` 为原点。

```text
dx = x - 50
dy = y - 50
```

- 当 `|dy| >= |dx|`：根据 `dy` 分为上方或下方。
- 否则：根据 `dx` 分为左方或右方。

## 4. 双方视角换算

### 蓝色方

| 固定地图方向 | 蓝方视角 |
| --- | --- |
| 下方 | 己方红区 |
| 左方 | 己方蓝区 |
| 上方 | 对方红区 |
| 右方 | 对方蓝区 |

### 红色方

| 固定地图方向 | 红方视角 |
| --- | --- |
| 上方 | 己方红区 |
| 右方 | 己方蓝区 |
| 下方 | 对方红区 |
| 左方 | 对方蓝区 |

## 5. 统计分母

一个样本只有同时满足以下条件才会参与统计：

- 所在比赛已填写双方队名；
- 每方五个分路均已唯一设置；
- 目标时间不超过比赛时长；
- 最近采样点与目标时间之差不超过采样容差；
- `confidence >= 0.5`。

因此不同队伍、分路、时间点的 `validMatches` 可能不同。概率表必须同时展示有效场次数，不能只展示百分比。

## 6. 修改规则时的要求

区域边界属于数据语义。修改 `local-ui/app.js` 中的 `regionName()` 时必须：

1. 同步更新本文件；
2. 更新 README 的区域摘要；
3. 更新数据格式的 `regionDefinition` 描述；
4. 用代表性坐标覆盖蓝红双方的七类输出；
5. 说明历史导出是否仍可直接比较。
